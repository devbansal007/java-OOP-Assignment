# Java OOP Assignment: Bank Account Management System

This project demonstrates Java classes, objects, constructors, encapsulation, and instance methods.

## Files

- `BankAccount.java` — defines account details and deposit, withdrawal, balance-checking, and display methods.
- `Main.java` — creates two independent accounts and demonstrates transactions.

## Run the program

Compile both files:

```bash
javac BankAccount.java Main.java
```

Run:

```bash
java Main
```

Each `BankAccount` object stores its own balance, so transactions on one account do not affect the other.
